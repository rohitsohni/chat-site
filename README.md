# Chat Site

Full-stack real-time chat application with authentication, profile management, online presence, image uploads, and one-to-one messaging.

## Project Highlights

- Built a React and Tailwind CSS interface for one-to-one messaging, onboarding, and profile management.
- Developed Node.js and Express REST APIs with JWT-protected routes and MongoDB persistence for users and messages.
- Integrated Socket.IO for real-time delivery, with reconnect refresh and connection-aware fallbacks.
- Added Cloudinary-backed image sharing within conversations.

## Tech Stack

React, Tailwind CSS, Node.js, Express.js, MongoDB, Socket.IO, Cloudinary
